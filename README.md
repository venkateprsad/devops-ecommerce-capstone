
# DevOps Ecommerce Capstone

## Project Overview
End-to-End DevOps CI/CD Microservices Project using AWS, Linux, Docker, Git, GitHub, Jenkins and Ansible.

## Project 1: CI/CD Pipeline
- AWS EC2 Ubuntu server
- Git and GitHub for source code management
- Jenkins for CI/CD automation
- Docker for containerization
- Docker Compose for application deployment
- GitHub Webhook for automatic Jenkins builds

## CI/CD Workflow
1. Developer pushes code to GitHub.
2. GitHub Webhook triggers Jenkins.
3. Jenkins pulls the latest source code.
4. Jenkins executes the pipeline.
5. Docker builds the application image.
6. Docker Compose deploys the application.
